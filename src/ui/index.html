Como conectar

    Modelos disponíveis

    Clique em ⧉ para copiar o nome exato de um modelo e usar na API (campo model de /v1/chat/completions). Use Procurar modelos na aba Testar API para atualizar a lista.

    Conexão da API

    Endpoints

    Login na DeepSeek

    A sessão do navegador é necessária para o chat funcionar.
    Em servidor remoto, o navegador abre numa "tela virtual". Abrir login remoto (VNC)

    Login no Qwen

    A sessão do navegador (chat.qwen.ai) é necessária para o chat com modelos Qwen.
    Conversas

    Chat

    Você não está logado na DeepSeek. O chat só funciona com uma sessão válida.
    Multi-turno preservado pelo servidor. Se API_KEY estiver configurada no .env, cole-a no campo API Key da aba Conexão.

    Console de teste

    A requisição é feita para com a API Key preenchida acima. Se nenhuma chave for informada, a requisição sai sem Authorization.

    Exemplos de consumo da API

    Substitua SUA_API_KEY pela chave do seu .env. Sem chave configurada, basta remover o cabeçalho Authorization.
